# SMTP Bench Pro v0.2.6

## Resumo

A versão **0.2.6** fecha a linha 0.2.x adicionando exportação de comparação histórica.

A comparação continua sendo calculada uma única vez a partir de duas execuções persistidas. A exportação consome exclusivamente o objeto `RunComparison` já existente e não executa rede, não consulta novamente o repository, não chama `HistoricalRunComparator`, não reavalia regras de segurança e não recalcula findings.

## Principais mudanças

- Exportação de comparação histórica para JSON.
- Exportação de comparação histórica para HTML standalone.
- Serialização canônica `serialize_comparison()`.
- Metadata de exportação com `export_type = historical_comparison` e `format_version = 1`.
- Relatório HTML com seções de resumo, performance, SMTP, TLS, command diagnostics e security findings.
- Escaping obrigatório de conteúdo histórico no HTML.
- Botão `Exportar Comparação` no diálogo de comparação.

## Segurança

O exportador representa somente o snapshot comparativo já calculado. Ele não acessa servidor SMTP, não autentica, não envia comandos e não executa probes.

## Compatibilidade

- Integration API: 1
- SQLite schema: 3
- Sem migration nesta versão
- Sem alteração no Bench Pro Core
- Sem alteração no DNS Bench Pro
