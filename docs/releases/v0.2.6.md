# SMTP Bench Pro v0.2.6

## Resumo

A versão **0.2.6** fecha a linha 0.2.x adicionando **Historical Comparison Export**.

A comparação continua sendo calculada uma única vez a partir de duas execuções persistidas. A exportação consome exclusivamente o objeto `RunComparison` como fonte de verdade e não executa rede, não consulta novamente o repository, não chama `HistoricalRunComparator`, não reavalia o Security Rule Engine e não recalcula findings.

## Principais mudanças

- Exportação de comparação histórica para JSON.
- Exportação de comparação histórica para HTML standalone.
- Serialização canônica `serialize_comparison()`.
- Metadata de exportação com `export_type = historical_comparison` e `format_version = 1`.
- Relatório HTML com seções de resumo, performance, SMTP, TLS, command diagnostics e security findings.
- HTML escaping obrigatório de conteúdo histórico e de dados originados de servidores.
- Botão `Exportar Comparação` no diálogo de comparação.

## Segurança

O exportador representa somente o snapshot comparativo já calculado. Ele não acessa servidor SMTP, não autentica, não envia comandos e não executa probes.

A versão mantém as fronteiras de segurança da linha 0.2.x:

- não executa autenticação SMTP real;
- não envia mensagens;
- não executa `MAIL FROM`, `RCPT TO` ou `DATA`;
- não implementa teste de Open Relay;
- não executa enumeração de usuários.

## Known Limitations

- Comparison exports are currently JSON and HTML only.
- PDF comparison export is not available in this version.
- Comparison is based exclusively on persisted historical snapshots.
- Missing information from legacy runs is represented as unavailable/null.
- Partial historical runs may limit comparison accuracy.
- SPF, DKIM, DMARC, MTA-STS and TLS-RPT diagnostics are outside the 0.2.6 scope.
- RBL checks and scoring are outside the 0.2.6 scope.
