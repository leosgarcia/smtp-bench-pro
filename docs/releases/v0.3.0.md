# SMTP Bench Pro v0.3.0 — Mail DNS Diagnostics

## Summary
SMTP Bench Pro 0.3.0 introduces a comprehensive, offline-first **Mail DNS Diagnostics** engine capable of auditing MX routing, A/AAAA resolution, PTR/FCRDNS alignment, SPF (RFC 7208) syntax and lookup budgets, and DMARC (RFC 7489) policies with Public Suffix List organizational domain resolution.

## Key Features
- **Mail DNS Resolver**: High-performance, cancellable DNS diagnostic service built on `dnspython`.
- **MX & PTR / FCRDNS Diagnostics**: Detection of primary/secondary MX servers, Null MX (RFC 7505), A/AAAA records, and Forward-Confirmed Reverse DNS (FCRDNS) mapping.
- **SPF Engine (RFC 7208)**: Full term parser, qualifier evaluator, lookup budget tracker (10 DNS lookups limit, 2 void lookups limit), and syntax validator.
- **DMARC Engine (RFC 7489)**: Policy extractor (`p`, `sp`, `pct`, `adkim`, `aspf`, `rua`, `ruf`), subdomain inheritance, and `tldextract` offline Organizational Domain resolution.
- **Mail DNS Security Rule Engine**: Pure rule evaluator executing 11 frozen security finding rules across MX, PTR, SPF, and DMARC.
- **SQLite Schema v4**: Full, atomic persistence of `MailDNSRunSnapshot` linked to benchmark runs with cascade deletion.
- **GUI "DNS de E-mail" Tab**: PySide6 tab featuring domain input, live progress, 4 summary cards, and 4 detailed sub-tabs (Routing, SPF, DMARC, Findings).
- **History & Export Integration**: Historical read-only snapshot viewer and canonical JSON / HTML report exporters with 100% HTML XSS escaping.

## Integration & Schema
- **Integration API**: 1 (Fully compatible with `benchpro-core`)
- **SQLite Schema Version**: 4
- **Backward Compatibility**: Fully compatible with Schema v1, v2, v3 databases and legacy historical runs.

## Known Limitations
- DKIM signature verification, MTA-STS (RFC 8461), and TLS-RPT (RFC 8460) deferred to v0.4.0.
- Standalone Mail DNS diagnostics persist a synthetic `benchmark_runs` entry with `iterations=0` (WG-001).
- States without frozen findings (e.g. `SPFStatus.INVALID_SYNTAX`, `DMARCStatus.MULTIPLE`) are displayed in full diagnostic details but do not generate synthetic Security Finding IDs in v0.3.0.
