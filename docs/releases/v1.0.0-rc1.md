# SMTP Bench Pro v1.0.0-rc1

SMTP Bench Pro 1.0.0-rc1 é a release candidate que consolida o produto como ferramenta profissional de diagnóstico SMTP e DNS de e-mail, com foco em segurança conservadora, histórico reproduzível e exportação fiel de evidências.

## Destaques

- benchmark SMTP consolidado;
- diagnostics SMTP e TLS/certificate;
- perfis SAFE, EXTENDED e MANUAL;
- histórico auditável com export JSON/HTML;
- comparação histórica persistida com export JSON/HTML;
- Mail DNS Diagnostics com MX, A/AAAA, PTR/FCRDNS, SPF, DKIM e DMARC;
- integração com Bench Pro Core via Integration API v1;
- packaging Windows inicial com PyInstaller;
- About alinhado ao padrão visual do DNS Bench Pro.

## Known Limitations

- sem AUTH real;
- sem envio de e-mail;
- sem Open Relay test;
- sem autodiscovery DKIM;
- sem validação real de assinatura DKIM;
- sem MTA-STS;
- sem TLS-RPT;
- sem MSI/NSIS nesta fase;
- sem score 0-100;
- sem PDF;
- comparações e exports dependem de snapshots persistidos.

## Security Boundaries

O produto continua conservador por padrão. VRFY e EXPN permanecem restritos aos perfis Estendido e Manual, e nenhuma funcionalidade de envio ou autenticação SMTP real é executada.
