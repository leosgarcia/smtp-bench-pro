# Guia Rápido

## Interface Standalone

Execute:

```bash
python -m smtp_bench_pro
```

## Bench Pro Core

Instale o módulo ao lado do Core e execute:

```bash
python -m benchpro_core
```

## Fluxos principais

- Benchmark SMTP.
- Diagnóstico SMTP/TLS.
- Segurança SMTP.
- Histórico auditável.
- DNS de E-mail.

## DNS de E-mail

Informe um domínio e, quando necessário, selectors DKIM manuais.

O diagnóstico cobre MX, A/AAAA, PTR/FCRDNS, SPF, DKIM e DMARC.
